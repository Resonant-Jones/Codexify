# Ephemeral Cited Migration Chronicle Preview

The preview endpoint is `POST /api/imports/history/chronicle/preview` on the existing migration router and feature gate. It accepts one canonical Project, a bounded imported thread and origin selection, the existing evidence limits and offset, `migration_chronicle_preview`, strict interpretation consent, `recallable_archive`, and a nonempty list of reviewed `{thread_id, message_id, digest}` references.

The endpoint resolves the authenticated account principal and obtains fresh request-local Chronicle authorization. The earlier authorization-check response has no authority here. The endpoint rereads evidence, requires identical Project, thread, origin, and bounded-window scope, and recomputes each reviewed excerpt's SHA-256 digest. Client excerpt text is never trusted or used to construct model input.

The model-exposure gate verifies current reader excerpts with exact reviewed digests, imported message provenance, complete non-truncated text, non-escalating canonical, importer, and original roles, and an explicit per-message `approve_for_local_chronicle: true`. Historical system, developer, and tool roles are data and are rejected. Fresh Project/thread/diary/modeling exclusions remain authoritative. Where no separate applicable sensitive-topic restriction is configured, the authenticated owner's explicit approval authorizes that exact message for this request only; unknown, conflicting, or unavailable required policy raises `BLOCKED_POLICY`. A digest, request-wide consent, or local provider selection cannot substitute for the approval or override exclusions.

Inference uses Guardian's existing `chat_with_ai` seam with `provider="local"`, bounded output, zero tools, strict provider selection, and one local request. Cloud providers, remote embeddings, search, connectors, queues, and fallback model paths are not used by the preview. Local unavailability fails closed with HTTP 503; invalid evidence selections and malformed model output return HTTP 422. Thread and origin scope comparisons are order-independent and preserve exact membership.

The model returns JSON containing an optional summary and at most twelve observations in the categories themes, decisions, milestones, preferences, and unresolved_work. Each observation is limited to 250 characters and requires one to three citations. The validator accepts a citation only when its Project, thread, message, origin, and exact quote are present in the admitted evidence. Fabricated IDs, unsupported quotes, malformed output, and unsupported claims fail closed. Historical preferences and activity remain historical evidence; no current setting or task is created.

The response is marked `derived` and `ephemeral`, includes generation and read times, selected scope, bounded coverage, provenance omissions, window and archive-completeness fields, and explicit uncertainty. It sets `Cache-Control: no-store`. No Chronicle, memory, identity, continuity, task, embedding, search, consent, log, or source-history record is written.

This implementation provides a bounded human approval path, not a complete Continuity Governance Surface or sensitivity classifier. Archive authorization, reviewed-message integrity, explicit per-message approval, exclusion precedence, and local-only dispatch are tested. Unit tests prove envelope construction, local transport arguments, JSON parsing, and citation validation; structural citation checks do not prove semantic entailment. Approval is request-local and non-persistent, and the preview remains ephemeral and zero-write. Live local-model behavior, semantic claim support, frontend consent, and deployed qualification remain unproven; release posture remains HOLD.
