# Qualification Baselines

No broad human-UX baselines are established yet.

Initial private-preview qualification should preserve raw observations and sample sizes rather than inventing thresholds from one or two testers.

## Current policy

- Contract failures use rubric-defined blocking criteria.
- Human friction is recorded and compared over time.
- Assistance level is not yet assigned a universal PASS threshold.
- Task timing is not yet assigned a universal PASS threshold.
- Confidence scores are descriptive until enough runs exist to define a useful baseline.

When a baseline is introduced, this file must record:

- metric;
- population;
- sample size;
- date range;
- environment/profile;
- calculation;
- rationale;
- whether it is informational or blocking.

Historical run receipts must not be rewritten when baselines change.
