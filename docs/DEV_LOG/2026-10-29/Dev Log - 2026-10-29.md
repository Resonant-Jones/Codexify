# Dev Log - 2026-10-29

The shape of this day was subtraction. Nearly every significant change made something smaller: a claim narrowed to a named path, a named revision, a specific set of checks. There was real product motion too — Saved Widget gained a promotion route, the chat view gained a minimap, two schemas were prepared for review — but the day's governing theme was the difference between asserting that a system works and recording the exact conditions under which it was observed to work.

The migration qualification was the clearest instance. Running the committed chain against both an empty database and a restored, read-only copy of the Preview database, and watching every pre-existing row survive, is a meaningfully stronger statement than "the migrations run." But the rehearsal that followed it may have been more valuable still, because it surfaced two traps: the backend entrypoint's `alembic` call is swallowed, and the migrator reads migrations from the baked image rather than the mounted source. Anyone following the earlier recipe would have believed they had migrated when they had not. Those two lines are worth more than a green line of output.

The Preview work followed the same discipline. Twenty of twenty checks passed at serving revision `5569f3f34`, across two accounts, covering isolation and idempotency and the absence of a sender-visible receipt. Then the serving revision advanced to `c8e72ef86` — ignore files and documentation only, so the application source is identical. It would have been easy, and tempting, to treat that as continuity. The record instead states the thing that is true: source equivalence is an observation about code, not a re-execution of the checks. That sentence is the difference between a receipt and an assumption, and it costs almost nothing to write.

The release-truth work was the quieter thread and possibly the more durable one. Binding a blocker-completion claim to the obligation that owns it, distinguishing unresolved proof adjectives from completion claims, preserving coordinated predicates, rejecting contradictory posture claims — each of these closes a specific way for the system to congratulate itself without having done anything. The corpus behind them grew by hundreds of lines of cases. This is the machinery that keeps the rest of the record honest; if it drifts, every other receipt quietly becomes decorative.

Meanwhile the product kept moving in ways the release envelope does not yet reflect. A Guardian-authorized Saved Widget promotion route, with a provenance snapshot and revision readback, is a real operation with a real authority boundary. Conversation minimap navigation is real usability. The Guardian coding-worker ownership schema and the campaign approval-provenance schema are real persistence. All of it is either persistence-only or server-side, and none of it is a user-facing Save control, a Library, a supported release, or an autonomous execution path. ADR-105 records the governing contract for human approval and operator identity; it grants nothing on its own.

The honest summary is that 2026-10-29 produced a system that knows more about itself and promises less. The migration chain is qualified on one PostgreSQL path against two dataset shapes. The Preview is deployed, read state is live-qualified at one revision, and the unread badge is now proven in a real browser — in Chrome 156 only. The release gate is HOLD, and the reasons are enumerated rather than atmospheric: no fresh current-tip Compose run, no restart recovery, no explicit-model rejection, no cross-browser badge coverage, no share-link expiry or revocation.

What this makes possible next is unglamorous and specific. Re-run the twenty checks against the serving tip. Freeze a SHA and run the whole supported-path proof bundle. Fix the credential-boundary documentation so the implementation and the accepted authority rule say the same thing. Then let the browser badge, the Saved Widget lifecycle, and the import-to-recall path receive the same treatment these receipts just received — measured on a named surface, at a named revision, with the limits written down.
