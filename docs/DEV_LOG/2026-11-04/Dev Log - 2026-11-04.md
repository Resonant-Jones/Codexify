### Two fences for the coding worker's terminalization race (PR #996, open)

The deepest correctness work of the day sat on one boundary: a worker that never held a durable claim could terminalize a run owned by another worker. Two executors attacked it independently, and one closed its branch in favour of the other's repair.

- PR #996 (`fix/guardian-coding-preacceptance-terminal-race-20261104`, open): `a7cb9eb02` added `terminalize_unclaimed_queued_run()`, a single conditional `UPDATE` carrying the queued state and the absence of worker ownership in the same write that establishes the terminal state, so there is no earlier ownership check that can go stale between the check and the write. It added `finalize_unclaimed_coding_result()`, which stages the canonical result writes on one session and commits them only when that same atomic decision accepts them, so an unfenced result write can no longer persist a coding-result artifact or a source-thread message over an accepted run. `17971661f` then removed a PostgreSQL-only guard that had suppressed the correction rather than strengthened it — the decision is one conditional statement and does not depend on any dialect's row-lock semantics — and `03cf432c4` scoped the refusal to the run's deployment, requiring `deployment_id` and holding the deployment-then-run lock order the acceptance path already uses, so the three terminal paths cannot deadlock against each other. `11f5dda06` added the result-write counterpart of the three status-path orderings the proof already had.
- The competing branch (`fix/coding-worker-claim-less-terminalization-20261104`) closed with proof only. `e648ac6df` had written a fence of its own; `579cc4dc6` restored the superseded implementation to the branch base and kept only the dated proof document, because PR #996 owns the canonical repair. `04cd15fb8` then reconciled against PR #996's verified state at `11f5dda06` by checking that branch in source rather than from either report.

Two executors, one authority, and the losing branch kept its dated evidence instead of its duplicate code. That is the outcome worth having, and it happened without either side overwriting the other.
