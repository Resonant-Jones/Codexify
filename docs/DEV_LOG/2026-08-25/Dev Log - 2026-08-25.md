# Narrative Log - 2026-08-25

Today was a runtime qualification day, but not in the simplistic sense of making a green box turn green. The work was about separating several different kinds of evidence that had been sitting close together: tester chat, retrieval initialization, worker readiness, Watchdog dispatch, model execution, image retention, and Pi diagnostics.

The tester path produced a meaningful result. One proof-only account completed an ordinary local Gemma turn through the normal worker and queue path, with Redis-stream, API, and Postgres readback agreeing on the task and persisted assistant message. That is real evidence. It is also bounded evidence. It came from the tester stack and does not prove the current supported Compose profile, retrieval quality, or release readiness.

The Chroma work made the other side of that distinction concrete. The historical derived index was preserved before retirement, and the old panic did not recur in the guarded recovery attempt. The fresh state then hit a different, safety-redacted failure. The later diagnosis classified that failure against a disposable empty-store control without turning the diagnosis into permission to retry, restore data, or change the implementation. Postgres stayed canonical; Chroma stayed derived.

The same discipline carried into the GitHub Watchdog merge. Mainline now contains a substantial Guardian-owned preparation and execution seam: authenticated delivery intake, durable receipt lineage, immutable review snapshots, policy-bound attempts, dispatch records, and a dedicated worker. But the worker qualification stopped before receipt creation and model invocation because the required Watchdog policy/model was missing or unavailable. It did not inherit the ambient chat model, and nothing was published back to GitHub. That failure is more useful than a synthetic pass would have been.

The image-retention proof was similarly narrow. It established that a previously qualified immutable image was gone and that the mutable tag pointed elsewhere. It did not establish who deleted it, how it disappeared, or whether a Docker event was retained. The Pi changes stayed in the same category: repair the diagnostic seam and metadata, but do not claim OAuth or provider support.

The deeper change is that the system is learning to carry evidence with its boundary attached. A completion can be real without being release proof. A worker can be ready without having executed a task. A queue can accept an envelope without a model result existing. An image can be lost without its deletion cause being known. That is the level of precision required for the next round of current-main proof.
